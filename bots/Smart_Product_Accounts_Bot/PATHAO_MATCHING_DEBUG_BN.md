# Pathao Matching Debug

Bot menu থেকে `🧩 Matching Debug` অথবা `/pathao_match_debug` চালান।

এটি সর্বোচ্চ ৩টি active parcel নিয়ে Pathao API response-এর Merchant Order ID ও Consignment ID imported database-এর সঙ্গে মিলিয়ে দেখাবে। কোনো হিসাব পরিবর্তন করবে না।

রিপোর্টে থাকবে:
- Pathao Merchant Order ID
- API Consignment ID
- Database match হয়েছে কি না
- কোন key দিয়ে match হয়েছে
- Product ও imported COD
- Current status এবং sync করলে কী action হবে
