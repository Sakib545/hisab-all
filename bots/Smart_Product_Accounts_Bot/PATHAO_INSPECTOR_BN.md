# Pathao Inspector

নতুন Menu: `🩺 Pathao Inspector`
Command: `/pathao_inspector`

এটি দেখাবে:
- API configured কিনা
- Auto Sync ON/OFF
- batch limit ও request delay
- last successful sync
- order status summary
- last sync counts
- rate limit / error
- একটি truncated raw API sample

Raw sample-এ credentials থাকে না; তবুও screenshot public জায়গায় share করবেন না, কারণ order/consignment data থাকতে পারে।
